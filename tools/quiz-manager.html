💡 使用说明
  1. 点击「打开目录」选择项目中的 public/quizzes/ 文件夹
  2. 列表中会显示所有 JSON 题库文件 — 已注册到 manifest.json 的为启用状态
  3. 拖拽行首的 ⠿ 手柄可调整题库显示顺序
  4. 拨动开关可启用/禁用题库（控制是否出现在 manifest.json 中）
  5. 点击 🗑️ 可删除题库文件（删除前会要求确认，并自动备份）
  6. 修改完成后点击「💾 保存修改」— 将写入 manifest.json 并处理删除
  7. ⚠️ 删除操作不可撤销，建议先下载备份

⚡ 使用 File System Access API（Chrome/Edge 支持），不支持时自动回退到手动模式。
